Bilal Smart Library v0.7.3 — تعليمات رفع GitHub

سبب هذه النسخة:
ملف GitHub Actions كان موجودًا داخل الحزمة السابقة، لكن المجلد .github لم يصل إلى المستودع، لذلك لم تعمل أي جدولة صباحًا أو مساءً.

المطلوب عند الرفع:
1) فك ضغط الحزمة كاملة.
2) شغّل prepare_github_workflow.bat مرة واحدة على Windows.
3) تأكد أن هذا المسار موجود داخل المجلد:
   .github/workflows/keepalive.yml
4) ارفع جميع محتويات المجلد إلى جذر مستودع smart_library، وليس الملفات الظاهرة فقط.
5) بعد الرفع افتح تبويب Actions في GitHub. يجب أن يظهر Workflow باسم:
   Bilal Smart Library Keep-Alive
6) شغّل Run workflow يدويًا أول مرة. نجاحه يعني ظهور علامة خضراء، وسيصل Ping إلى Supabase.

الجدولة الحالية:
- 03:00 UTC = حوالي 06:00 صباحًا بتوقيت قطر.
- 15:00 UTC = حوالي 18:00 مساءً بتوقيت قطر.
- GitHub قد يؤخر التشغيل المجدول عدة دقائق حسب الضغط، لذلك لا تعتمد على الثانية الدقيقة.

مهم:
الملف KEEPALIVE_GITHUB_ACTIONS.yml الموجود في جذر الحزمة هو نسخة مرئية احتياطية فقط. GitHub لا يشغّله من الجذر. الملف التنفيذي الحقيقي يجب أن يكون حصريًا في:
.github/workflows/keepalive.yml

لا يوجد Vercel Cron في هذه النسخة؛ vercel.json يبقى {} حتى لا تتعارض خطة Hobby مع الجدولة.
