# Bilal Smart Library — v0.5 Cloud Pro

نسخة سحابية كاملة مرتبطة فعليًا بمشروع Supabase:

- Project: `bilal Smart Library`
- Project Ref: `xruvbsbmvpntczaydhpo`
- المدرسة: **مدرسة بلال بن رباح النموذجية للبنين**
- التخزين: Supabase PostgreSQL + Auth + RLS + Edge Functions

## التشغيل لأول مرة
1. افتح `setup_admin.html`.
2. أدخل اسم أول مدير، بريده الإلكتروني، وكلمة مرور لا تقل عن 6 أحرف.
3. أدخل رمز التهيئة الموجود في `FIRST_ADMIN_TOKEN.txt`.
4. بعد نجاح الإنشاء افتح `index.html` وسجّل الدخول بنفس البريد وكلمة المرور.
5. رمز التهيئة يعمل مرة واحدة فقط. احذف ملف الرمز بعد إنشاء المدير.

> لا يوجد أي `service_role` أو مفتاح سري داخل الحزمة. المفتاح الموجود في `cloud-config.js` هو Publishable Key المسموح بوضعه في تطبيق الويب، والحماية الفعلية تتم عبر Auth + RLS + Edge Functions.

## تجربة 5 طلاب و5 كتب
للتجربة العملية:
1. سجّل الدخول كمدير أو أمين مكتبة.
2. من الطلاب أضف 5 طلاب أو استورد قالب Excel الموجود في `templates`.
3. اطبع بطاقات الطلاب.
4. من الكتب أضف 5 كتب/نسخ أو استورد قالب الكتب.
5. اطبع ملصقات الكتب والصقها على النسخ.
6. افتح محطة الاستعارة.
7. امسح بطاقة الطالب ثم باركود الكتاب.
8. افتح الإرجاع السريع وامسح باركود الكتاب.
9. افتح النظام من جهاز ثانٍ بنفس الحساب أو بحساب محطة منفصل للتأكد أن البيانات تظهر لحظيًا من نفس القاعدة.

## قارئ الباركود
القارئ المطلوب في المرحلة الحالية: قارئ USB يعمل كـ Keyboard HID ويرسل Enter بعد القراءة. لا يحتاج Driver خاص في أغلب الأجهزة.

- طالب: مثال `ST000001`
- نسخة كتاب: مثال `BK000001-01`
- الرقم الشخصي لا يطبع داخل الباركود.

## RFID
قاعدة البيانات والواجهة تحتويان من الآن على UID للطالب والكتاب، والمحطات تدعم `barcode / rfid / hybrid`. عند شراء قارئ RFID لاحقًا نربط الـSDK أو UID مع نفس دورة الاستعارة دون تغيير بنية البيانات الأساسية.
