# Bilal Smart Library v0.5.1 Cloud Pro

هذه النسخة مرتبطة بقاعدة Supabase السحابية الخاصة بالمشروع.

## التشغيل
1. شغّل `start_cloud.bat` أو افتح النسخة عبر خادم محلي بسيط.
2. افتح `index.html`.
3. سجّل الدخول بحساب المدير الذي تم إنشاؤه وربطه مسبقًا.

## إضافة مدير ثانٍ أو ثالث
من داخل لوحة المدير:
- افتح **المستخدمون والصلاحيات**.
- اضغط **+ مستخدم**.
- أدخل الاسم والبريد الإلكتروني وكلمة المرور.
- اختر الدور **مدير النظام**.
- اضغط **حفظ**.

يمكن أيضًا اختيار أدوار: أمين المكتبة، محطة استعارة، أو مشاهدة فقط.

## حماية مهمة
النظام يمنع إيقاف أو تغيير صلاحية آخر مدير نشط، حتى لا تُغلق لوحة الإدارة على المستخدمين.

## التخزين السحابي
الطلاب والكتب والنسخ والاستعارات والإرجاعات والحجوزات والمستخدمون والمحطات والإعدادات محفوظة في Supabase Cloud.
