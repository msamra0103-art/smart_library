# منارة المكتبة الذكية — v0.4 Library Pro

المرحلة الثانية من النظام، مطوّرة للعمل محليًا أو عبر الشبكة الداخلية للمدرسة، بدون ربط سحابي في هذه النسخة.

## الحسابات الافتراضية
- مدير النظام: `admin` / `1234`
- أمين المكتبة: `librarian` / `1234`
- يمكن فتح محطة الاستعارة الذاتية مباشرة من شاشة الدخول دون إعطاء الطالب صلاحيات لوحة الإدارة.

> ملاحظة: حسابات v0.4 محلية ومخصصة للمرحلة التجريبية. غيّر كلمات المرور من شاشة المستخدمين، ولا تعتبرها بديلًا عن مصادقة خادم حقيقية.

## ما الجديد في v0.4
- استيراد الطلاب دفعة واحدة من **Excel XLSX أو CSV**.
- استيراد الكتب والنسخ دفعة واحدة من **Excel XLSX أو CSV**.
- قوالب Excel جاهزة داخل مجلد `templates` ويمكن تنزيلها من داخل البرنامج.
- توليد الأكواد الناقصة تلقائيًا عند الاستيراد، مع فحص التكرارات قبل الإدخال.
- سجل طالب كامل: البيانات، الكتب الحالية، تاريخ الاستعارات، الحجوزات.
- سجل كتاب كامل: البيانات الببليوجرافية، المستعير الحالي، التاريخ، قائمة الانتظار.
- تجديد الاستعارة مع حد أقصى قابل للتحكم ومنع التجديد عند وجود حجز لطالب آخر.
- نظام حجوزات وقائمة انتظار للنسخة.
- حسابات وصلاحيات: **مدير النظام** و**أمين المكتبة**.
- لوحة مدير تختلف في اختصاراتها وصلاحياتها عن لوحة أمين المكتبة.
- تقارير متقدمة حسب التاريخ، الصف، التصنيف والمحطة.
- مؤشرات: أكثر الكتب، أكثر الطلاب قراءة، التصنيفات، المحطات، ونسب التشغيل.
- تصدير سجلات الاستعارة والمتأخرات والتقارير وسجل العمليات إلى CSV.
- إدارة محطات متعددة بأسماء ومواقع ومعرفات مستقلة.
- تجهيز كامل لحقول RFID للطلاب والكتب، ووضع قارئ Barcode / RFID / Hybrid.
- سجل تدقيق يوضح المستخدم والمحطة لكل عملية.
- نسخ احتياطي JSON واستعادة كاملة.

## وضع 1: التشغيل المحلي السريع
افتح `index.html` مباشرة.

في هذا الوضع تحفظ البيانات داخل متصفح الجهاز نفسه. مناسب لجهاز واحد وتجارب الاستعارة والباركود.

## وضع 2: عدة أجهزة في نفس الوقت على شبكة المدرسة LAN
هذه النسخة تحتوي على خادم محلي بسيط بدون أي حزم خارجية.

### Windows
1. ثبّت Node.js إذا لم يكن موجودًا.
2. شغّل `start_library.bat`.
3. ستظهر نافذة سوداء بها عنوان مثل:
   - `http://localhost:8787`
   - وعنوان آخر يبدأ بعنوان IP للجهاز مثل `http://192.168.1.25:8787`
4. على الكمبيوتر الرئيسي افتح عنوان localhost.
5. على محطات الاستعارة الأخرى افتح عنوان IP الظاهر، بشرط أن تكون الأجهزة على نفس الشبكة.
6. إذا طلب Windows Firewall السماح لـ Node.js على الشبكة الخاصة، اسمح له على شبكة المدرسة الخاصة فقط.

### ماذا يضيف وضع LAN؟
- جميع الأجهزة ترى نفس الطلاب والكتب والاستعارات.
- الخادم يحفظ قاعدة مركزية في `data/library.json` عند التشغيل.
- عمليات الاستعارة والإرجاع والتجديد والحجز تمر بمعاملات مركزية.
- إذا حاول جهازان استعارة النسخة نفسها في اللحظة نفسها، يقبل الخادم عملية واحدة فقط ويرفض الثانية.
- كل عملية تسجل اسم المحطة التي نُفذت منها.

## استيراد الطلاب من Excel
استخدم القالب الموجود داخل البرنامج أو الملف:
`templates/قالب_استيراد_الطلاب.xlsx`

الأعمدة المدعومة:
- اسم الطالب (إلزامي)
- الرقم الشخصي
- الصف
- الشعبة
- كود الطالب — اختياري، النظام يولده إذا كان فارغًا
- RFID — اختياري

البرنامج يفحص: تكرار الكود، الرقم الشخصي وRFID، ويعرض معاينة قبل الاستيراد.

## استيراد الكتب من Excel
استخدم:
`templates/قالب_استيراد_الكتب.xlsx`

الأعمدة المدعومة:
- عنوان الكتاب (إلزامي)
- المؤلف
- التصنيف
- الرف
- باركود النسخة — اختياري ويمكن توليده
- رقم العهدة
- ISBN
- الناشر
- السنة
- RFID

كل نسخة فعلية يجب أن تكون بسجل مستقل وكود مستقل.

## الحجوزات والتجديد
- يمكن إنشاء حجز لطالب على نسخة كتاب.
- الحجز النشط يمنع طالبًا آخر من استعارة النسخة قبل صاحب الدور الأول.
- عند استعارة صاحب الحجز تتحول حالة الحجز إلى مكتمل.
- التجديد يمدد تاريخ الإرجاع حسب مدة الاستعارة المحددة.
- يمنع التجديد إذا تم استهلاك الحد المسموح أو إذا كان هناك حجز نشط لطالب آخر.

## RFID Ready
لا تحتاج لشراء RFID الآن. النظام أُعد من هذه النسخة بحيث توجد قيمة RFID مستقلة لكل طالب ولكل كتاب، ويمكن للقارئ العمل في وضع:
- Barcode
- RFID
- Hybrid

عند تركيب القارئ لاحقًا سيستخدم النظام UID بنفس منطق كود الباركود. أي تكامل خاص مع SDK لجهاز معين يمكن إضافته دون تغيير قاعدة البيانات المنطقية.

## الباركود
- النوع: Code 39.
- مثال طالب: `ST000001`.
- مثال نسخة كتاب: `BK000001-01`.
- الرقم الشخصي لا يطبع داخل الباركود.
